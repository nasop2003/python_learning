# ログイン認証システム

## 概要
- コンソール上で動くとても簡単なログイン認証システムです（データ保存などはされません）

## 機能
- ユーザー名・パスワードを一件登録できます（終了時にログイン情報は消失されます）
- ログインでユーザー名とパスワードを入力し、認証できます（パスワードを3回間違えるとプログラム終了）

## 使い方
`login.py`を実行
コンソール上で以下の項目を番号で選択(番号以外、空白の場合はエラーメッセージ表示されます)
1) ユーザー情報入力
2) ログイン
3) 終了

### ユーザー情報入力
- ユーザー名とパスワードを登録

### ログイン
- ユーザー情報とパスワードを入力（パスワードを3回間違えるとプログラム終了、未登録の場合はエラーメッセージが表示されます）

## 動作環境
- Python 3.12.10
- 外部ライブラリなし
