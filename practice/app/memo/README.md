# 簡易メモ帳

## 概要
- コンソール上で動く簡易メモ帳です

## 機能
- コンソール上でメモの記入・閲覧

## 使い方
`memo.py`を実行
コンソール上で以下の項目を数字で入力(空白・数字以外・文字列等を入力時にエラーメッセージが表示されます)
1) メモを書く
2) メモを見る
3) 終了

### メモを書く
- 内容を入力・登録時にtxtファイルが生成され、入力内容を保存

### メモを見る
- 記入したメモの内容を閲覧

## 動作環境
- Python 3.12.10
- ライブラリなし（全て）

## ファイル構成
```
memo/
├── memo.py     # メインプログラム
└── README.md   # プログラムの説明(当ファイル)
```
