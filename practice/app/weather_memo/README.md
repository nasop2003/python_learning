# 天気メモ帳

## 概要
コンソール上で動く天気メモ帳アプリです

## 機能
- 今日の気温を入力、天気(晴れ・くもり・雨・雪)、を選択し登録
- メモ登録時に現在日時が登録
- 登録済メモを一覧で表示

## 使い方
`weather_memo.py`を実行(起動時にjsonファイルが生成)
コンソール上で以下の項目を番号で選択(正しく入力しないとエラーメッセージを表示)
1) メモ作成
2) メモ一覧
3) 終了

### メモ作成
- 今日の気温(文字列は入力不可。小数入力可能)を入力
- 天気を番号にて選択、メモ（空欄でも可）を入力し登録
- 同日のメモがある場合は登録不可
- 登録時にjsonファイルにて保存

### メモ一覧
- 登録済のメモを一覧で表示(日付・気温・天気・メモの順)

### 終了
- プログラム終了

## 動作環境
- Python 3.12.10
- 外部ライブラリなし
