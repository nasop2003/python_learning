# 簡易タイマー

## 概要
コンソール上で動く簡易タイマーです

## 機能
- タイマーの設定に任意の秒数を設定
- タイマーの記録
- タイマーの記録内容を閲覧

## 使い方
`timer.py`を起動
コンソール上で以下の項目を番号で選択(正しく入力しないとエラーメッセージが表示されます)
1) 実行
2) 記録内容表示
3) 終了

### 実行
- 秒数を入力(0秒・数字以外を入力するとエラーメッセージが表示)
- カウントダウン終了時に記録するか選択(yかnを入力)

### 記録内容表示
- 記録内容を表示(日付・時間も表示される)

### 終了
- プログラムを終了

## 動作環境
- Python 3.12.10
- 外部ライブラリなし
