# テキストメモ帳

## 概要
- tkinterで動くテキストメモ帳です

## 機能
- メモの作成・検索・編集ができます（メイン画面で選択）
- 登録済みのメモを閲覧できます

## 使い方
1. `text_memo.py`を実行(起動時にjsonファイルが生成されます)
2. メイン画面でメモ作成・メモ検索・メモ編集をボタン選択（選択時に別ウィンドウにて表示）
3. メモ作成: タイトル・本文・タグを登録（本文・タグは省略可、タイトル未入力の場合はエラーメッセージを表示）
4. メモ検索: 左側の入力項目にて内容を入力して検索(部分一致)。検索時に右画面に検索結果を表示
5. メモ編集: 右画面のメモを選択し、編集・削除のいずれかを選択。編集の場合は別ウィンドウにて編集

## 動作環境
- Python 3.12.10
- 外部ライブラリなし
