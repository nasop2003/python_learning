# 買い物システム

## 概要
- コンソール上で動く買い物システムです

## 機能
- 商品・数量・値段を設定(無制限)(データ保存はされません)
- お会計時に購入日時(時間も表示)・登録した商品一覧・合計値段を表示
- 合計額が5,000円以上なら10%割引
- 合計金額・割引額は小数点第一位まで表示

## 使い方
`shopping.py`を起動
コンソール上で以下の項目を数字で入力(正しく入力しないとエラーメッセージが表示されます)
1) お買い物をする
2) お会計
3) 終了

### お買い物をする
- 商品名・数量・値段を設定

### お会計
- 設定した商品の一覧・合計金額を表示
- 割引額を表示(5,000円以上、割引されない場合は0円と表示)

## 動作環境
- Python 3.12.10
- 外部ライブラリなし
