# 家計簿アプリ

## 概要
- Tkinterで作った簡易家計簿です

## 機能
- 日付・種別(支出/収入)・カテゴリ・金額・メモを登録
- 日付はカレンダー選択
- カテゴリはプルダウン選択式（カテゴリは固定）
- メモを記入可能（空欄でも可能）
- 画面の一番下に登録した家計簿の一覧が表示
- 家計簿一覧は種別(支出/収入)の切り替えボタンにて切り替え
- 家計簿一覧の右に金額合計が表示(収入・支出・収支)

## 使い方
1. `kakeibo.py`を実行(起動時にjsonファイルとcsvファイルが生成されます)
2. 日付・種別・カテゴリを選択、金額・メモ（空白でも可）を入力。金額欄は空白、文字列を入力するとエラーメッセージが表示されます
3. 登録時にcsvファイル(kakeibo.csv)ファイルに情報が保存されます

## 動作環境
- Python 3.12.10
- tkcalender  (インストールコマンド: `pip install tkcalender`)
