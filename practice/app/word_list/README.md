# 単語帳

## 概要
コンソール上で動く英単語帳アプリです
英単語と日本語訳を登録し、実際に問題を解くことができます

## 機能
- 英単語と日本語訳の登録
- 英単語の一覧表示
- 登録済の英単語をランダムで出題
- テスト結果の集計・結果表示

## 使い方
`word_list`を起動(起動時にjsonファイルを作成)
以下の項目を番号で入力し、選択する(正しく入力しないとエラーメッセージを表示)
1) 単語登録
2) テスト
3) 集計・結果表示
4) 終了

### 単語登録
- 英単語と日本語訳を登録
- 英単語はアルファベットのみ入力可能(数字・記号・日本語は入力不可)
- 日本語訳は日本語のみ入力可能(数字・記号・アルファベットは入力不可)
- 既に同じ英単語がある場合は登録不可
- 登録時に英単語と日本語訳をjsonファイルにて保存

### 単語一覧表示
- インデックス番号付きで登録済の英単語を一覧表示

### テスト
- ランダムで登録済の英単語を出題、回答を入力
- 正解・不正解時にテスト結果をjsonファイルにて保存(問題・回答・結果・回答日時)

### 集計・結果表示
- テストの合計正解・不正解数を数字で表示

### 終了
- プログラムを終了

## 動作環境
- Python 3.12.10
- 外部ライブラリなし
