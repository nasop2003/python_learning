# ToDoリスト

## 概要
コンソール上で動くTodoリスト作成システムです

## 機能
- タスク名を登録(jsonファイルにて保存)
- 登録時に現在日時を登録
- 登録済Todoリストの閲覧
- 登録済Todoリストの削除

## 使い方
`Todolist.py`を実行
コンソール上で以下の項目を番号で選択(正しく入力しないとエラーメッセージを表示)
1) 追加
2) 表示
3) 削除
4) 終了

### 追加
- 起動時にjsonファイル作成
- タスク名を入力（文字列のみ登録可能）
- 数字や記号を入力するとエラーメッセージを表示
- 登録時にタスク名と現在日時をjsonファイルにて保存

### 表示
- 登録済みのタスクをすべて表示(インデックス番号も表示)
- jsonファイルがない場合はエラーメッセージを表示

### 削除
- 登録済みのタスクを番号で指定し削除

### 終了
- プログラムを終了

## 動作環境
- Python 3.12.10
- 外部ライブラリなし

## ファイル構成
```
todolist/
├── README.md       # プログラムの説明(当ファイル)
├── todolist.json   # 記録ファイル
└── Todolist.py     # メインプログラム
```
